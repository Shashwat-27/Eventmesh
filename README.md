# EventMesh

EventMesh is a multi-tenant event delivery infrastructure that reliably
delivers application events to registered webhook consumers.

## Core Capabilities

- Event ingestion
- Asynchronous event processing
- Webhook delivery
- Retry with exponential backoff
- Dead Letter Queue
- HMAC-SHA256 signatures
- API key authentication
- Rate limiting
- Idempotency
- Delivery tracking
- Multi-tenant architecture

## Tech Stack

- Node.js
- TypeScript
- Express.js
- PostgreSQL
- Prisma
- Redis
- BullMQ
- Next.js
- Docker
- k6
